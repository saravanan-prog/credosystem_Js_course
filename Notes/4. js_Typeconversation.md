## 1. Types of Conversion

### 1. `Implicit` 

 JavaScript converts `automatically`

    
#### 1.1 `Number` becomes `string`

   ``` 
   let result = "5" + 2;
   console.log(result);               →  "52"

   
    (+)  → string concatenation if one is string

   ```

#### 1.2  `String` becomes `number`

    ```
    let result = "5" - 2;
    console.log(result);               →  3

    (-, *, /)   → convert everything to number

    ```

        





###  2. Explicit 

 You convert `manually`

#####   2.1 Convert to `Number`

        Number("10")       →  10
        Number("abc")      →  NaN ❌


#### 2.2 `Convert` to `String`

```
String(100)       →  "100"

```  

### 2.3 `Convert` to `Boolean`

```
Boolean(1)         →  true
Boolean(0)         →  false
Boolean("")        →  false
Boolean("hi")      →  true
```
