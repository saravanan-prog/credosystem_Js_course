# 🧱 Synchronous vs Asynchronous

#### ✅ 1. Synchronous (Blocking)

-  Code runs line by line, one after another
- Next line waits until current line finishes

#### Example

```
console.log("Start");
console.log("Task 1");
console.log("End");

✅ Output

    Start
    Task 1
    End

👉 Everything runs in order

```



#### ❌ Problem with Sync
```
console.log("Start");

// Heavy task (imagine 5 seconds)
for (let i = 0; i < 1e9; i++) {}

console.log("End");

👉 UI freezes / app becomes slow 😓

```

# 🚀 2. Asynchronous (Non-blocking)

- Tasks can run in background
- Program does NOT wait

#### Example

```

console.log("Start");

setTimeout(() => {
  console.log("Task done");
}, 2000);

console.log("End");

✅ Output

    Start
    End
    Task done



👉 setTimeout runs later (async)

````
