# 🧱 Synchronous vs Asynchronous

#### ✅ 1. Synchronous (Blocking)

-  Code runs `line by line`, one` after another`
-  Next line waits `until current line finishes`

#### Example

```
console.log("Start");
console.log("Task 1");
console.log("End");

✅ Output

    Start
    Task 1
    End

👉 Everything runs in order

```



#### ❌ Problem with Sync
```
console.log("Task 1");
console.log("Task 2");
console.log("Task 3");

for (let i = 0; i < 1e9; i++) {}   // Heavy task (imagine 5 seconds)

console.log("Task 4 ");
console.log("Task 5 ");

console.log("End");

👉 UI freezes / app becomes slow 😓

```

# 🚀 2. Asynchronous (Non-blocking)

- Tasks can run in background
- Program does NOT wait

#### Example

setTimeout runs later (async) 
```

console.log("Task 1");
console.log("Task 2");
console.log("Task 3");

setTimeout(()=>{
    for (let i = 0; i < 1e9; i++) {}
},3000)
   

console.log("Task 4 ");
console.log("Task 5 ");

console.log("End");



 

Output:
  Task 1
  Task 2
  Task 3
  Task 4
  Task 5
````
