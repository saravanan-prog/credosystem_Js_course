## 1. Global Scope (Big Box)

Global Scope = everywhere 🌍

```
var a = 10;

function test() { 
    console.log(a);   Everyone can use it ✅
}

console.log(a)

```

## 2. Function Scope (Box inside box)

- Function Scope = inside function only 🔒

```
    function test() {
        var b = 20;                  
        console.log(b);              
    }

     console.log(b);    Outside ❌ cannot access
```  


## Block Scope

    
 Block Scope = inside {} only 📦


```
if(true){
  let y = 200;
}
```
console.log(y); // ❌ error
