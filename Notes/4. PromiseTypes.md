# 🔧 2. Promise Types (with clear examples)

#### ✅ 1. Promise.resolve()

- Already successful promise

```
    let greetings = Promise.resolve("Hello")

    greetings
        .then( data => console.log(data) );

```
#### ❌ 2. Promise.reject()

- Already failed promise

```
    let greetings = Promise.reject("Error")

    greetings
        .then( data => console.log(data));
        .catch(err => console.log(err));

```

#### 🔗 3. Promise chaining

- One result flows into next

```
let number = Promise.resolve(10)


number
  .then(num => num * 2)                    // 20
  .then(num => num + 1)                    // 21
  .then(result => console.log(result));
  .catch(error => console.log(error))
  
```

#### 🧵 4. Promise.all()

- 👉 All must succeed
- ❌ If one fails → everything fails

```
let number1 =  Promise.resolve(1),
let number2 =  Promise.resolve(2),
let number3 =  Promise.resolve(3)

Promise.all([
 number1,
 number2,
 number3
])
.then(res => console.log(res)); // [1,2,3]
.catch(error => console.log(error))

```



#### ⚡ 5. Promise.race()

- 👉 First finished wins

```
function one(){
    return new Promise((resolve,reject)=>{

        setTimeout(() => resolve("Fast"), 3000)
    })
}
function two(){
    return new Promise((resolve,reject)=>{

        setTimeout(() => resolve("Fast"), 2000)
    })
}

function three(){
    return new Promise((resolve,reject)=>{

        setTimeout(() => resolve("Fast"), 500)
    })
}





Promise.race([
    one,
    two,
    three
])
.then(res => console.log(res)); // Fast

```

#### 🏁 6. Promise.allSettled()


- 👉 Waits for all (success + failure)

```

let number1 =  Promise.resolve(1),
let number2 =  Promise.resolve(2),
let number3 =  Promise.reject("Error")

Promise.allSettled([
  number1,
  number2,
  number3
])
.then(res => console.log(res))
.catch(error => console.log(error))
;

```

#### 🎯 7. Promise.any()

- 👉 First success wins
```

let number1 =   Promise.reject("Error"),
let number2 =   Promise.resolve("Success")



Promise.any([
 number1,
 number2
])
.then(res => console.log(res)); // Success

```
