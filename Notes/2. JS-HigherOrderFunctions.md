# 1. Higher-Order Functions (HOFs)

A function that:
- takes another function as an argument, OR
- returns a function

Official JS documentation term.
Includes:

```
forEach() → loops through each element but does not return anything
map()     → transforms every element and returns a new array
filter()  → returns a new array with elements that match a condition
find()    → returns the first element that matches a condition
reduce()  → reduces the array to a single value using an accumulator
some()    → returns true if at least one element matches a condition
every()   → returns true if all elements match a condition
```

### 🔁 1. forEach() — simple loop

- loops through each element but does not return anything

```
let nums = [1, 2, 3];
nums.forEach((value,index,array) => {
   console.log("value===>",value)
});

```

### ✨ 2. map() — transform like magic

- transforms every element and returns a new array

```
let nums = [1, 2, 3];

let result  = nums.map((value,index,arr) => {
    return value * 2
}); 

 // output : [2, 4, 6]

 ```


### 🔍 3. filter() — remove unwanted data

- returns a new array with elements that match a condition

```

let nums = [1, 2, 3, 4];
let even = nums.filter((value,index,arr) => {
    return value % 2 === 0
});

// output : [2, 4]
```

### 🧠 4. reduce()
- reduces the array to a single value using an accumulator
```
let nums = [1, 2, 3, 4];

let sum = nums.reduce((acc, value,index,arr) => {
    return acc + value
},  0);

// output : 10

```


## ❓ 5. some() & every()

#### some() → at least one
- returns true if at least one element matches a condition
```
let arr  = [1, 2, 3]
let isAvailable = arr.some( value => value > 2); // true

```


#### every() → all must pass
- returns true if all elements match a condition
```
let arr  = [1, 2, 3]
let isAvailable = arr.every( value => value > 0); // true

```
