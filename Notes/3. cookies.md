# Cookies

#### ✅ Create cookie (JavaScript)
```
document.cookie = "name=Saravanan; expires=Fri, 31 Dec 2026 12:00:00 UTC; path=/";
```
#### 🔍 Read cookies
```
console.log(document.cookie);
```
#### 👉 Output:
```
name=Saravanan

```
❌ Delete cookie
```
document.cookie = "name=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/";
```
#### ⚙️ Cookie properties

| Property   | Meaning                             |
| ---------- | ----------------------------------- |
| `expires`  | When cookie should expire           |
| `path`     | Where cookie is accessible          |
| `domain`   | Which domain can access             |
| `secure`   | Only HTTPS                          |
| `HttpOnly` | Not accessible via JS (server only) |



#### 🔑 Cookies vs Storage

| Feature        | Cookies           | localStorage |
| -------------- | ----------------- | ------------ |
| Size           | ~4 KB             | ~5–10 MB     |
| Sent to server | ✅ Yes             | ❌ No         |
| Expiry         | Can set           | Manual       |
| Security       | Better (HttpOnly) | Less secure  |


#### 🎯 When to use cookies

- Authentication (login sessions)
- Tracking users
- Remember small data
#### ⚠️ Important
- Limited size (4KB)
- Slower (sent with every request)
- Don’t store large data


#### Final understanding

- 👉 Cookies = small data + server communication
- 👉 Used mainly for login/session management
