#### 1. Why it’s needed
```
const user = {};
console.log(user.profile.name);

❌ Error:
  - Cannot read properties of undefined
  - Because profile doesn’t exist.
```


#### 2. Using Optional Chaining

```
const user = {};
console.log(user.profile?.name);

✅ Output:
undefined
```
👉 It stops safely instead of crashing.

#### 3. How it works
```
object?.property
If object exists → continue
If null/undefined → return undefined
```

#### 4. Nested Example
```
const user = {
  profile: {
    name: "Saravanan"
  }
};

console.log(user.profile?.name);     // Saravanan
console.log(user.address?.city);     // undefined
```
#### 5. With Arrays
```
const users = [];
console.log(users[0]?.name);
```
👉 Safe if array is empty

#### 6. With Functions
```
const user = {};
user.sayHello?.();

```

👉 Calls only if function exists

#### 7. Combine with ?? (default value)
```
const name = user.profile?.name ?? "Guest";
console.log(name);
```
#### 8. Real Example (API data)
```
const data = {
  user: {
    details: null
  }
};

console.log(data.user?.details?.email);
```
👉 No runtime error

#### 9. Important Rules

#### ✅ Correct:
```
user?.profile?.name
```
#### ❌ Wrong:

```
user?.profile.name
```

## Summary
- ?. prevents crashes
- Returns undefined if missing
- Works with objects, arrays, functions
- Often used with ??
