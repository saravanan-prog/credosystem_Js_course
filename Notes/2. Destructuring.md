# Destructuring

### Simple Object Desctructure.

```
  const product = {
    name : "apple",
    qty  : 5
    price : 200
    availability : true
  }
  /* de structure */
  
  const {
    name,
    qty,
    price,  
    availability 

  } = product



  console.log("Product Name ====>",name)
  console.log("Product qty ====>",qty)
  console.log("Product price ====>",price)
  console.log("Product availability ====>",availability)

```
