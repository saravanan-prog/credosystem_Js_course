# Fetch API

- The Fetch API in JavaScript is used to make HTTP requests 
- (like calling APIs, getting data from a server, sending data, etc.).

🧠 Simple idea
```
👉 Fetch = “Go get data from somewhere (server/API)”
```
#### ✅ Basic syntax
```
fetch("https://api.example.com/data")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.log(error));
```
#### 🔍 How it works
```
fetch(url)          → sends request
response            → comes back from server
response.json()     → convert to JS object
data                → actual usable data
```

#### 📥 Example (GET request)
```
fetch("https://jsonplaceholder.typicode.com/users")
  .then(res => res.json())
  .then(data => {
    console.log(data);
  });
```

#### 📤 Example (POST request)
```
fetch("https://jsonplaceholder.typicode.com/users", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "Saravanan",
    age: 25
  })
})

.then(res => res.json())
.then(data => console.log(data));

⚡ Modern way (async/await)
```
#### Cleaner and easier:
```
async function getData() {
  try {
    const res = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = await res.json();
    console.log(data);
  } catch (error) {
    console.log(error);
  }
}
```
getData();

#### ⚠️ Important points
- fetch() returns a Promise
- It does not fail on HTTP errors (like 404) → you must check:
- if (!res.ok) throw new Error("Error");
- 👍 When to use Fetch
```
Calling APIs 🌐
Loading data dynamically
Sending form data
```
