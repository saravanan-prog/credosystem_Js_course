# ⚡ JavaScript Operators

👉 Operators are used to perform operations on values (operands)

#### 1. Arithmetic Operators

Used for calculations



```

    let a = 10;
    let b = 5;

    console.log(a + b); // 15
    console.log(a - b); // 5
    console.log(a * b); // 50
    console.log(a / b); // 2
    console.log(a % b); // 0
    console.log(a ** b); // power → 100000
```
#### 2. Assignment Operators
```
let x = 10; // normal assignment

x += 5; // additon assignment
x -= 3; // subraction assignment
x *= 2; // multiplication assginment
x /= 4; // division assignment
```

#### 3. Comparison Operators

👉 Compare values → return true / false

```
console.log(5 == "5");   // true (loose)
console.log(5 === "5");  // false (strict)

console.log(10 > 5);     // true
console.log(10 < 5);     // false
console.log(10 >= 10);   // true
console.log(10 <= 9);    // false

```


🔥 Important


```
👉 Always prefer:

===   // strict equality
```


#### 🟣 4. Logical Operators
```
 (&&) AND -  [all conditon true]  = true otherwise false
 (||) OR  -  [any condition true] = true otherwise false
  (!)  Not -  [Negativity check]


console.log(true && false); // false (AND)
console.log(true || false); // true  (OR)
console.log(!true);         // false (NOT)

```


#### 🟠 5. Increment / Decrement

```
let i = 5;

i++; // 6
i--; // 5

🔍 Pre vs Post
let a = 5;

console.log(a++); // 5 (then becomes 6)
console.log(++a); // 7

```
#### 🧩 6. Ternary Operator

👉 Short form of if...else

```
    let age = 18;

    let result = age >= 18 ? "Adult" : "Minor";
    console.log(result);
```


#### ⚙️ 7. Type Operators

```
typeof "Hello"  // "string"
typeof 10       // "number"

```




#### 🚀 8. Spread & Rest Operators
```
#### Spread

let arr = [1, 2, 3];
let newArr = [...arr, 4]; // spread

#### Rest

function display(...args){  // Rest
    console.log(args)
}

```
