# JavaScript Promise

- A JavaScript Promise is a` cleaner way` to handle `asynchronous operations`
- basically an improvement `over callbacks`.
- Instead of passing a function to be called later

#### 1. Basic Promise syntax
```
  const promise = new Promise((resolve, reject) => {

    let flag = true
    
    if (flag) {
        resolve("Success");
    } else {
        reject("Failed");
    }
 });

```



#### 2. Promise states

A Promise can be in one of three states:

```
Pending     → still working
Fulfilled   → success (resolve)
Rejected    → failure (reject)
```






#### ✅ Basic example
```
const myPromise = new Promise((resolve, reject) => {
  let success = true;

  if (success) {
    resolve("Task completed!");
  } else {
    reject("Something went wrong.");
  }
});

myPromise
  .then(result => {
    console.log(result);
  })
  .catch(error => {
    console.log(error);
  });

```
