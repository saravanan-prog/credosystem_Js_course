# 🧱 JSON vs JavaScript Object

####  1. JavaScript Object

```
    const user = {
        name: "Saravanan",
        age: 25,
        isLoggedIn: true,
        greet() {
            console.log("Hello");
        }
    };


```

## Features
- Can have functions (methods) ✅
- Keys can be without quotes ✅
- Used inside JavaScript code


### ✅ 2. JSON (JavaScript Object Notation)

```
{
  "name": "Saravanan",
  "age": 25,
  "isLoggedIn": true
}

```

#### Features
- ❌ No functions allowed
- ✅ Keys must be in double quotes
- Used for data exchange (API, server, storage)



## 🔁 Convert Between Them
#### Object → JSON
```
const user = { name: "Sara", age: 25 };

const json = JSON.stringify(user);

console.log(json);

👉 Output:

{"name":"Sara","age":25}

```

#### JSON → Object
```
const json = '{"name":"Sara","age":25}';

const obj = JSON.parse(json);

console.log(obj.name);

```
