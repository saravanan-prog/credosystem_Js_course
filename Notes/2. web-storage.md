# localStorage and sessionStorage

- Both localStorage and sessionStorage are part of the browser’s Web Storage.
- API. They let you store data in the user’s browser as key–value pairs.

#### 🧠 Simple idea

- Store small data in browser (like memory)
- No server/database needed

#### 🔑 Key difference
| Feature  | localStorage                       | sessionStorage            |
| -------- | ---------------------------------- | ------------------------- |
| Lifetime | Stays even after closing browser ✅ | Deleted when tab closes ❌ |
| Scope    | Shared across tabs                 | Only same tab             |
| Size     | ~5–10 MB                           | ~5 MB                     |
| Use case | Remember user                      | Temporary data            |


#### ✅ localStorage example
 Store data
 ```
localStorage.setItem("name", "Saravanan");
 ```
Get data

```
let name = localStorage.getItem("name");
console.log(name);
 ```
Remove

```
localStorage.removeItem("name");
```
#### ✅ sessionStorage example
 ```
sessionStorage.setItem("user", "Saravanan");
 ```
 ```
let user = sessionStorage.getItem("user");
console.log(user);
 ```
###### 📦 Store object (important)

Storage only supports strings, so convert:

```
let user = { name: "Saravanan", age: 25 };

localStorage.setItem("user", JSON.stringify(user));
 ```
###### Get object from store
  ```
let data = JSON.parse(localStorage.getItem("user"));
console.log(data.name);
 ```
#### ⚠️ Important points
- Stores only strings
- Not secure ❌ (don’t store passwords)
- Data stays in browser

## 🎯 When to use

#### Use localStorage:
- Remember login (simple apps)
- Save theme (dark/light)
- Store preferences

#### Use sessionStorage:
- Temporary form data
- One-time session info

```
👍 Final understanding
👉 localStorage = long-term storage
👉 sessionStorage = temporary storage
```
