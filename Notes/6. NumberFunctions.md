
# Number functions

👉 Number functions = tools to work with numbers

Example:

```
let num = 10.567;
```

## 🔥 Important Number Functions

#### 1. toFixed() → round number

```
let num = 10.567;
let fixedValue = num.toFixed(2)    👉 Output: 10.57

👉 (keeps 2 digits after decimal)
```



#### 2. toString() → number → string

```
let num = 10.567;
let strNum = num.toString()    👉 Output: "10.57"

```


#### 3. parseInt() → string → integer
```
let num = "100px";
let parseInteger = parseInt(num)    👉 Output: 100
```


#### 4. parseFloat() → string → decimal

```
let num = "10.25abc";
let parseInteger = parseFloat(num)    👉 Output: 10.25
```


#### 5. Number() → convert to number
```
let num = "123"; 
let parseInteger = Number("123")       👉 Output: 123
```



#### 6. isNaN() → check if NOT a number

```
let num = "abc"; 
let isNumber = isNaN(num)           👉 Output: true
 
```

#### 7. Math.round() → nearest number

```
let num = 4.6
let isNumber = Math.round(num)       👉  Output: 5

```
#### 8. Math.floor() → down

```
let num = 4.6
let isNumber = Math.floor(num)       👉 Output : 4

```

#### 9. Math.ceil() → up

```
let num = 4.6
let isNumber = Math.ceil(num)        👉 Output : 5

```



#### 10. Math.random() → random number

```
let otp = Math.random()             👉 Output : 0 to 1 (random)

```
