# 1. Spread Operator (...)

👉 Expands elements (unpacks values)

#### ➤ With Arrays
```
const arr1 = [1, 2];
const arr2 = [3, 4];

const result = [...arr1, ...arr2];

console.log(result); // [1, 2, 3, 4]

```

#### ➤ Copy Array
```
const arr = [1, 2, 3];
const copy = [...arr];
```
👉 Prevents mutation (important in React)

#### ➤ With Objects
```
const user = { name: "Saravanan" };

const updatedUser = { ...user, age: 25 };

console.log(updatedUser);
```

#### ➤ Override values
```
const obj = { a: 1, b: 2 };

const newObj = { ...obj, b: 10 };

console.log(newObj); // { a: 1, b: 10 }
```
#### ➤ Function arguments
```
const nums = [1, 2, 3];

console.log(Math.max(...nums)); // 3
```

# 2. Rest Operator (...)

👉 Collects multiple values into one

#### ➤ In arrays
```
const [a, b, ...rest] = [1, 2, 3, 4];

console.log(rest); // [3, 4]
```
#### ➤ In objects
```
const user = { name: "Saravanan", age: 25, city: "Chennai" };

const { name, ...others } = user;

console.log(others); // { age: 25, city: "Chennai" }
```
#### ➤ In functions
```
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b, 0);
}

console.log(sum(1, 2, 3, 4)); // 10
```
