## Variables (var, let, const)

👉 Used to store data

### 🔹 var (old way)

``` 
   var name = "Saravanan";
        
    ✔ Function scoped
    ❌ Issues: Can be re-declared

```

### 🔹 let (modern)

```
  let age = 25;
  
  ✔ Block scoped
  ✔ Can be updated



```


### 🔹 const (fixed value)
```
const pi = 3.14;


 ✔ Cannot reassign
 ✔ Block scoped

```


### ⚡ Difference

| Keyword | Scope    | Reassign | Redeclare |
| ------- | -------- | -------- | --------- |
| var     | Function | ✅        | ✅         |
| let     | Block    | ✅        | ❌         |
| const   | Block    | ❌        | ❌         |
