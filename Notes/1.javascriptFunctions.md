# JavaScript Function

    A function declaration defines a named function using the function keyword.

####  Syntax

```
    function functionName() {
        // code
    }

```
####  Example 

``` 
    function welcomeMessage() {
        return "Hello welcome to Javascript wolrd" ;
    }

    let welcomeData = welcomeMessage()
```
####  Syntax Parameterized Function
```
    function functionName(parameters) {
        // code
    }
    
```
#### Example 
```
    function greet(name) {

        return "Hello " + name;

    }

    let greetMessage = greet("Saravanan");

```
