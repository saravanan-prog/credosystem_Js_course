## ⚡ 1. Types of Conversion

#### 🟢 A. Implicit (Automatic)

👉 JavaScript converts automatically

    ```
    👉 Number becomes string

    let result = "5" + 2;
    console.log(result); // "52"

    ```
    👉 String becomes number

        let result = "5" - 2;
        console.log(result); // 3

        
    ```




## 🟡 B. Explicit (Manual)

👉 You convert manually

###  🔵 2. Convert to Number

        Number("10")   // 10
        Number("abc")  // NaN ❌


### 🟣 3. Convert to String

```
String(100) 
// "100"

```  

### 🟠 4. Convert to Boolean

```
Boolean(1)   // true
Boolean(0)   // false
Boolean("")  // false
Boolean("hi") // true
```
