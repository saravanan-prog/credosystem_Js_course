# Function Currying 

    Currying is a technique where a function takes one argument at a time and returns another function.


#### Currying (step by step)

```
function add(a) {
  return function(b) {
    return a + b;
  };
}

add(2)(3); 

```


### simple example

```
function greet(name) {
  return function(message) {
    console.log(name + ": " + message);
  };
}

greet("Saravanan")("Hello");
```
