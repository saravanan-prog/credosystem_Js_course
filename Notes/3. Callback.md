# Callback

- A JavaScript callback is simply a function that you pass as an argument to another function, 
- and it gets executed later—usually after some task finishes.

### Basic idea

- Instead of doing everything in sequence, you say:
```
“Run this function, and when you're done, call this other function.”
```
#### Example
```
function greet(name, callback) {
  
  setTimeout(()=> {
    console.log("Hello " + name);
     callback();
  } )
  
 
}

function sayBye() {
  console.log("Goodbye!");
}

greet("Saravanan", sayBye);

Output:

Hello Saravanan
Goodbye!

```


##### Here:

- sayBye is the callback function
- It gets passed into greet and executed later
- Why callbacks are used
- Callbacks are very common in:
```
        Asynchronous operations (like API calls, file reading)
        Event handling (clicks, inputs)
```
#### Async example
```
setTimeout(function() {
  console.log("This runs after 2 seconds");
}, 2000);

```
- The function inside setTimeout is a callback
- It runs after the delay.


#### Real-world example (API style)
```
function fetchData(callback) {
  setTimeout(() => {
    const data = { id: 1, name: "Saravanan" };
    callback(data);
  }, 1000);
}

fetchData(function(result) {
  console.log(result);
});
```
##### Important notes
- Callbacks can be synchronous or asynchronous
- Too many nested callbacks can lead to “callback hell”


##### Example of callback hell:
```
doSomething(function(result) {
  doSomethingElse(result, function(newResult) {
    doAnotherThing(newResult, function(finalResult) {
      console.log(finalResult);
    });
  });
});
```
##### Modern alternatives

To avoid callback hell, JavaScript now uses:

- Promises
- async/await
