# Callback

- A JavaScript **callback** is simply a function that you `pass as an argument to another function`,  
- usually after `some task finishes`
- and it gets `executed later`



#### Example

Before Callback
```
function greet(name) {
  setTimeout(()=> {
    console.log("Hello " + name);
  },3000)
}

function sayBye() {
  console.log("Goodbye!");
}

greet("Saravanan");
sayBye()

Output :
    Good Bye
    Hello Saravanan

```

After Callback

```
function greet(name,callback) {
  setTimeout(()=> {
    console.log("Hello " + name);
    callback();
  },3000)
}

function sayBye() {
  console.log("Goodbye!");
}

greet("Saravanan",sayBye);


Output :
    Hello Saravanan
    Good Bye
    

```



To avoid `callback hell`, JavaScript now uses:

- Promises
- async/await
