 # Javascript Loops

👉 Used to repeat code

### for loop

```
    for (let i = 1; i <= 5; i++) {
        console.log(i);
    }

    👉 Best when you know count

```
### for...in 
  
  - for-in-loop gives Keys only

```
let numbers = [10,20,30];

for (let i in numbers) {
    console.log(i);
}
```

### for - of - loop

- for-of  gives Values

```
    

        let arr = [10, 20, 30];

        for (let value of arr) {
            console.log(value); // 10, 20, 30
        }

```

### while loop

```
let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}
```

👉 Runs while condition is true

### do...while

```
let i = 1;

do {
    console.log(i);
    i++;
} while (i <= 5);

```

##  break & continue

### break

- Stops loop completely
```
for (let i = 1; i <= 5; i++) {
    if (i === 3) 
       break;
    console.log(i);
}

Output:
1
2
```
### continue

- Skips current iteration

```
for (let i = 1; i <= 5; i++) {
    if (i === 3) 
       continue;
    console.log(i);  
}

Output:

1
2
4
5

```
