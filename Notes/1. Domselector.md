# DOM Element selector

### 1. getElementById()

- Selects a single element by its id 
- `fastest` and most` specific`.

```
HTML:   <h1 id="header">Hello</h1>
JS:    const element = document.getElementById("header")

```
### 2. getElementsByClassName()

- Selects `all elements` with a `given class` 
- returns `HTMLCollection`.

```
HTML:  <h1 class ="content"> Hello </h1>
JS  : const element =  document.getElementsByClassName("content")
```

### 3. getElementsByTagName()

Selects elements by `tag name`.

```
HTML: <p> Hello </p>
JS:   const element =  document.getElementsByTagName("p")
```
### 4. querySelector() 

Selects the first matching element using CSS selectors.

```
const element =  document.querySelector(".item")   // class
const element =  document.querySelector("#header") // id
const element =  document.querySelector("p")       // tag
```
### 5. querySelectorAll() 

Selects all matching elements (returns NodeList).
```
const element = document.querySelectorAll(".item")


```

## Quick comparison

| Method                 | Returns         | Use case               |
| ---------------------- | --------------- | ---------------------- |
| getElementById         | single element  | unique id              |
| getElementsByClassName | live collection | multiple same class    |
| getElementsByTagName   | live collection | tag-based selection    |
| querySelector          | first match     | flexible CSS selection |
| querySelectorAll       | all matches     | most modern choice     |
