# DOM Element selector

### 1. getElementById()

Selects a single element by its id (fastest and most specific).

```
HTML:  <h1 id="header">Hello</h1>
JS:    document.getElementById("header")


```
### 2. getElementsByClassName()

Selects all elements with a given class (returns HTMLCollection).
```
document.getElementsByClassName("item")
```

### 3. getElementsByTagName()

Selects elements by tag name.
```
document.getElementsByTagName("p")
```
### 4. querySelector() ⭐ (most used)

Selects the first matching element using CSS selectors.
```
document.querySelector(".item")   // class
document.querySelector("#header") // id
document.querySelector("p")       // tag
```
### 5. querySelectorAll() ⭐

Selects all matching elements (returns NodeList).
```
document.querySelectorAll(".item")

You can loop through it:

document.querySelectorAll(".item").forEach(el => {
  console.log(el);
});
```

## Quick comparison

| Method                 | Returns         | Use case               |
| ---------------------- | --------------- | ---------------------- |
| getElementById         | single element  | unique id              |
| getElementsByClassName | live collection | multiple same class    |
| getElementsByTagName   | live collection | tag-based selection    |
| querySelector          | first match     | flexible CSS selection |
| querySelectorAll       | all matches     | most modern choice     |
