# 🧱 What is an Object?

👉 An object is a collection of key–value pairs.

```
Key → property name
Value → data or function
```

#### ✅ Basic Example

```
const user = {
  name: "Saravanan",
  age: 25,
  isLoggedIn: true
};
```
####  Access Values

```
console.log(user.name);       // Saravanan
console.log(user["age"]);     // 25

```
#### Add / Update Property

```
const user = {
  name: "Saravanan",
  age: 25,
  isLoggedIn: true
};




user.city = "Chennai";   // add
user.age = 26;           // update

```
####  Delete Property
```
delete user.isLoggedIn  
```


#### 🔹 Object with Methods

```
const user = {
  name: "Saravanan",

  greet() {
    console.log("Hello " + this.name);
  }
};

user.greet();

```


#### 🔥 Nested Object

```
const user = {
  name: "Sara",
  address: {
    city: "Chennai",
    pincode: 600001
  }
};

console.log(user.address.city);

```

# Useful Built-in Methods

```

    const user = {
        name: "Saravanan",
        age: 25,
        isLoggedIn: true
    };




    Object.keys(user);    // ["name", "age",isLoggedIn]
    Object.values(user);  // ["Saravanan",25,true]
    Object.entries(user); // [ [name, saravanan],[age,25] ] 

```
