# Hoisting 

👉 Hoisting = JavaScript moves variables & functions to the top (before running code)

```
    console.log(a);  // undefined
    var a = 10;
```
### Because JavaScript internally does this:

```
    
     var a;            // moved to top (hoisted)
     console.log(a);  // undefined
     a = 10;

```

#### 🎯 Simple meaning:

👉 Declaration goes up
👉 Value stays in place



```

sayHi();

function sayHi() {  
  console.log("Hi");     // 👉 This works ✅
}

```
