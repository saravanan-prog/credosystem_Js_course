## Async / await

- It’s just a `simpler way to write Promises` 
- so your code looks like `normal synchronous code`.
- Instead of `.then()` and `.catch()`
-  You write `straight`, `readable` code

### Syntax:
```
async function getData() {
  const result = await promise;
  console.log(result);
}
```
- `async` → makes the function return a Promise.
- `await` → waits until the Promise is resolved.


#### ✅ Basic Example

```
function fetchData() {
  return new Promise(resolve => {
    setTimeout(() => {
      resolve("Data received");
    }, 1000);
  });
}

async function getData() {
  const result = await fetchData();  // When promise complete proceed next
  console.log(result);
}

```
