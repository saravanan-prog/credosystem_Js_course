# 🧠 What is async/await?

It’s just a simpler way to write Promises so your code looks like normal synchronous code.

```
👉 Instead of .then() and .catch()
👉 You write straight, readable code

```

#### ✅ Basic Example

```
function fetchData() {
  return new Promise(resolve => {
    setTimeout(() => {
      resolve("Data received");
    }, 1000);
  });
}

async function getData() {
  const result = await fetchData();  // When promise complete proceed next
  console.log(result);
}

```


### getData();
🔑 Rules (very important)

#### 1. async keyword
Makes a function return a Promise automatically

```
async function test() {
  return "Hello";
}

// same as:
Promise.resolve("Hello");

```
#### 2. await keyword
- Waits for a Promise to finish
- Can only be used inside async
```
const data = await fetchData();

❌ Error Handling (must know)
Use try...catch

async function getData() {
  try {
    const data = await fetchData();
    console.log(data);
  } catch (error) {
    console.log("Error:", error);
  }
}

```
#### 🔄 Multiple awaits

```
async function process() {
  const a = await Promise.resolve(1);
  const b = await Promise.resolve(2);
  console.log(a + b); // 3
}

⚡ Parallel execution (important optimization)
```

#### ❌ Slow way (runs one by one)
```
const a = await fetchA();
const b = await fetchB();

✅ Fast way (runs together)

const [a, b] = await Promise.all([fetchA(), fetchB()]);

```
🔁 Promise vs async/await


#### Promise style
```
fetchData()
  .then(data => console.log(data))
  .catch(err => console.log(err));

```
#### async/await style
```
try {
  const data = await fetchData();
  console.log(data);
} catch (err) {
  console.log(err);
}
```
#### 🧩 Simple Summary
- async → makes function return Promise
- await → waits for result
- try/catch → handles errors
- Cleaner than .then()

#### 🚀 Real-world example (API call)

```
async function getUsers() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log(error);
  }
}

getUsers();
```

- 👉 async/await = Promises made readable
