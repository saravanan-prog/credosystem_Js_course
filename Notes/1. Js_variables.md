## 2. Javascript Variables 
 
- Javascript variables are used to `store data`
- JavaScript provides three keywords to declare variables: `let`, `var`, `const`

###  `var` 

  `Function scoped`   —  A `var` variable is accessible within the function where it is declared.

``` 
function displayUser() {

    var age = 25;

    if (true) {

        var name = "Ram";

        console.log(age);   // ✅
        console.log(name);  // ✅
    }

    console.log(age);      // ✅
    console.log(name);     // ✅
}

displayUser()

```
 `Can be re-declared` —  ✅

```
   var candidateName = "Ramesh";
   var candidateName = "Kamlesh";
```
 `Can be re-assigned` —  ✅

```
   var candidateName = "Ramesh";
   candidateName = "Kamlesh";
```


### `let` 

  `Block scoped`  —  A let variable is accessible only inside the block { } where it is declared.


```
function test() {

    let age = 25;

    if (true) {

        let name = "Ram";

        console.log(age);       →    ✅
        console.log(name);      →    ✅
    }

    console.log(age);            →   ✅
    console.log(name);           →   ❌
}
```
  `Can be re-assigned`      — ✅
```
   let age = 25; 
   age = 35          → ✅ Allowed
```
  `Cannot be re-declared`   — ❌


```
   let age = 25; 
   let age = 30;     → ❌ Error
   age = 35          → ✅ Allowed

```

###  `const` 

 `Block scoped` — A const variable is accessible only inside the block { } where it is declared.

`Cannot be re-assigned` — ❌
```
const pi = 3.14;
pi = 3.15;          → ❌ Error

```
`Cannot be re-declared` — ❌

```
const pi = 3.14; 
const pi = 3.1;    → ❌ Error

```


### ⚡ Difference

| Keyword | Scope    | Reassign | Redeclare |
| ------- | -------- | -------- | --------- |
| var     | Function | ✅        | ✅         |
| let     | Block    | ✅        | ❌         |
| const   | Block    | ❌        | ❌         |
