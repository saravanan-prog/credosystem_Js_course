## 2. Javascript Variables 
 
- Javascript variables are used to `store data`
- JavaScript provides three keywords to declare variables: `let`, `var`, `const`

###  `var` 

-  `Function scoped`   —  A `var` variable is accessible within the function where it is declared.
-  `Can be re-declared` —  ✅
-  `Can be re-assigned` —  ✅

``` 
function displayUser() {

   var name = "Saravanan";
   var name = "Kumar";         →  ✅ Allowed

   var candidateAge = 25
   candidateAge = 36

}

displayUser()

```

### `let` 

-  `Block scoped`  —  A let variable is accessible only inside the block { } where it is declared.
-  `Can be re-assigned`      — ✅
-  `Cannot be re-declared`   — ❌

```
{

   let age = 25; 
   let age = 30;     → ❌ Error
   age = 35          → ✅ Allowed
}
```


###  `const` 

-  `Block scoped` — A const variable is accessible only inside the block { } where it is declared.
-  `Cannot be re-assigned` — ❌
-  `Cannot be re-declared` — ❌

```
const pi = 3.14; 
pi = 3.15;          → ❌ Error

```


### ⚡ Difference

| Keyword | Scope    | Reassign | Redeclare |
| ------- | -------- | -------- | --------- |
| var     | Function | ✅        | ✅         |
| let     | Block    | ✅        | ❌         |
| const   | Block    | ❌        | ❌         |
