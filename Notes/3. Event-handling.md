### 1. Basic Concept

- An event = user action
- An event handler = function that runs when the event occurs

### 2. addEventListener() ⭐ (best method)
```
element.addEventListener("event", function);
```
Example:
```
const btn = document.querySelector("button");

btn.addEventListener("click", () => {
  console.log("Button clicked!");
});

```

### 3. Common Events

#### ➤ Click
```
btn.addEventListener("click", () => {
  alert("Clicked!");
});
```
#### ➤ Input (typing)
```
const input = document.querySelector("input");

input.addEventListener("input", (e) => {
  console.log(e.target.value);
});
```
#### ➤ Submit (forms)

```
const form = document.querySelector("form");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // stop page reload
  console.log("Form submitted");
});
```

#### ➤ Mouse events
```
box.addEventListener("mouseover", () => {
  box.style.background = "yellow";
});
```

#### 4. Event Object (e)
```
btn.addEventListener("click", (e) => {
  console.log(e);
});
```
Useful properties:
```
e.target → element clicked
e.type → event type
e.preventDefault() → stop default behavior
```
#### 5. Old Method (not recommended)
```
btn.onclick = function() {
  console.log("Clicked");
};
```
👉 Problem: only one handler allowed

#### 6. Multiple Events Example
```
const box = document.querySelector("#box");

box.addEventListener("mouseenter", () => {
  box.style.background = "green";
});

box.addEventListener("mouseleave", () => {
  box.style.background = "red";
});
```
#### 7. Event Delegation (important concept 🔥)

Instead of adding many listeners, use one on parent:
```
document.querySelector("#list").addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    console.log("Item clicked:", e.target.innerText);
  }
});
```
#### 8. Real Example (Mini App)

```
const btn = document.querySelector("#btn");
const box = document.querySelector("#box");

btn.addEventListener("click", () => {
  box.textContent = "You clicked!";
  box.classList.toggle("active");
});
```

#### Summary

- Use addEventListener() for events
- Common events: click, input, submit, mouseover
- Use e (event object) for details
- Use preventDefault() for forms
- Learn event delegation for real apps
