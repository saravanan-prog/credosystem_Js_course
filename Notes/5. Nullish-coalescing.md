Nullish coalescing (??) is a JavaScript operator used to provide a default value only when something is null or undefined.

#### 1. Basic Syntax
value ?? defaultValue

👉 If value is:

null or undefined → returns defaultValue
otherwise → returns value
2. Example
const name = null;

console.log(name ?? "Guest");

👉 Output:

Guest
3. Why not use ||?

The || (OR) operator treats many values as false:

const count = 0;

console.log(count || 10); // 10 ❌ (wrong for this case)

👉 Because 0 is falsy

Correct with ??
const count = 0;

console.log(count ?? 10); // 0 ✅

👉 Only replaces if null or undefined

#### 4. More Examples
console.log(undefined ?? "Default"); // "Default"
console.log(null ?? "Default");      // "Default"
console.log(false ?? "Default");     // false
console.log("" ?? "Default");        // ""
#### 5. Combine with Optional Chaining ⭐
const user = {};

const name = user.profile?.name ?? "Guest";

console.log(name);

👉 Very common in real apps

6. Real Use Case
function greet(name) {
  const finalName = name ?? "Guest";
  console.log(`Hello ${finalName}`);
}

greet();        // Hello Guest
greet("Sam");   // Hello Sam
7. Important Rule

⚠️ Don’t mix ?? with || or && without parentheses:

// ❌ Syntax error
// a ?? b || c

// ✅ Correct
(a ?? b) || c
Summary
?? → default only for null / undefined
Better than || when 0, false, "" are valid values
Often used with optional chaining
Helps avoid unexpected bugs
