# 1. Changing Content

### ➤ innerText (text only)
- Updates visible text
- Ignores HTML tags inside

```
document.querySelector("#title").innerText = "Hello World";
```


### ➤ innerHTML (includes HTML)

- Can insert HTML elements
- Be careful with user input (security risk)


```
document.querySelector("#title").innerHTML = "<span>New Title</span>";
```


### ➤ textContent (fastest text update)

- Includes hidden text too
- Faster than innerText


```
document.querySelector("#title").textContent = "Updated Text";
```


# 2. Changing Styles

### ➤ Direct style change
```
document.querySelector("#box").style.color = "red";
```

### ➤ Multiple styles

👉 CSS properties become camelCase in JS:

```
    background-color    → backgroundColor
    font-size           → fontSize



    const box = document.querySelector("#box");
    box.style.backgroundColor = "blue";
    box.style.width = "200px";
    box.style.borderRadius = "10px";

```

# 3. Using Classes (Best Practice ⭐)

Instead of changing styles one by one, use CSS classes.
#### CSS:
```

    .active {
        background-color: green;
        color: white;
    }
```

## JS:

#### Add class
```
    document.querySelector("#box").classList.add("active");
```
#### Remove class

```
    document.querySelector("#box").classList.remove("active");
```

#### Toggle class

```
    document.querySelector("#box").classList.toggle("active");
```

### 4. Example (Real use case)
```
const btn = document.querySelector("button");
const box = document.querySelector("#box");

btn.addEventListener("click", () => {
  box.innerText = "Clicked!";
  box.style.backgroundColor = "orange";
  box.classList.add("active");
});
```
