# Function Closure

    A function remembers variables from its outer box


```

    function outer() {
        let a = 10;

        function inner() {
            console.log(a);
        }

        inner();
    }

    outer();
```
### 🧠 Diagram

```

    +----------------------+
    |   outer() BOX        |
    |----------------------|
    | a = 10               |
    | inner()              |
    +----------+-----------+
           |
           ↓
    +------------------+
    |   inner() BOX    |
    |------------------|
    | (no 'a' here)    |
    +------------------+

```
