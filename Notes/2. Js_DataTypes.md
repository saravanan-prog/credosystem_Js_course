#  Data Types

#### 1. `Primitive Types` -  Stores a single value

- String
- Number
- Boolean
- Null
- Undefined
- BigInt
- Symbol


```
    let name = "Ram";       →    String 
    let age = 25;           →    Number 
    let isActive = true;    →    Boolean 
    let x = null;           →    Null 
    let y;                  →    Undefined 
    let id = 123n;          →    BigInt 
    let symbol = Symbol();  →    Symbol
```
#### 2.  Reference Types - `Variable` stores a `reference` to an object in `memory`.

- Object
- Array
- Function
- Date
- Map
- Set

```    
    let arr = [1, 2, 3];                        → Array
    let person = { name: "Ram", age: 25 };      → Object
    let today = new Date();                     → Date           
```
