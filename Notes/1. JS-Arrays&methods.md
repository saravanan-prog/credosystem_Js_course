# 📦 What is an Array?

 An array is a collection of elements stored in a single variable.

```
let arr = [1, 2, 3, 4];
let mixed = [1, "hello", true, null];      //Array-List
```

# 🔧 Common Array Methods (Must Know)
## ➕ Add Elements

#### push() → add at end

```
    let arr = [1, 2];
    arr.push(3);                     //    Output : [1, 2, 3]
```

#### unshift() → add at beginning

```      
let arr = [1,2,3] 
arr.unshift(0);                 //    Output :  [0, 1, 2, 3]
```



## ➖ Remove Elements

#### pop() → remove from end
```
let arr = [1,2,3] 
arr.pop();                //  output : [1,2]      -> removes last
```
#### shift() → remove from beginning
```
let arr = [1,2,3]
arr.shift();            // output : [2,3]    -> removes first
```



## 🔍 Search
#### indexOf()
```
let arr        = [10, 20, 30]
let findIndex  = arr.indexOf(20);               // Output :  1
```
#### includes()

```
let arr        = [10, 20, 30]
let findResult = arr.includes(2);                // Output : false
```
## 🔄 Modify Array

#### splice() → add/remove

```       
let arr = [1, 2, 3];
arr.splice(1, 1);             //  Output :  remove 2 → [1, 3]
```

#### slice() → copy portion

```
let arr = [1, 2, 3, 4];
let part = arr.slice(1, 3);       //  Output : [2, 3]
```
##  Array to String

###  🔗 toString()
```
let array = ["a", "b", "c"]
let str   = array.toString();   // Output "a,b,c"

```

#### 🔗 join()

```
let array = ["a", "b", "c"]
let str   = array.join("-");    // Output "a-b-c"

```

## Sorting Function

#### Assending Order
```
const numbers= [100,50,25,200,80]
const soretedArr = numbers.sort((a,b) => a-b)  

 //  Output : [ 25, 50, 80, 100, 200 ]

```
#### Desending Order

```
const numbers= [100,50,25,200,80]
const soretedArr = numbers.sort((a,b) => b-a)   

//  Output : [ 200, 100, 80, 50, 25 ]
 
```
