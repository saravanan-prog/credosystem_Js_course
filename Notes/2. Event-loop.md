## JavaScript Event Loop Architecture (தமிழ் Diagram)

- "JavaScript என்பது `Single Threaded`.
-  Synchronous code-ஐ `Call Stack`-ல் Execute செய்யும்.
- Asynchronous operations-ஐ Browser `Web APIs` அல்லது `Node APIs`-க்கு அனுப்பும். 
- வேலை முடிந்ததும் `Promise callbacks`` Microtask Queue`-க்கு, 
- `setTimeout போன்ற callbacks` Callback Queue-க்கு செல்லும். 
- `Event Loop`, `Call Stack` காலியானதும் முதலில்` Microtask Queue`-யையும், 
- அதன் பிறகு `Callback Queue-யையும்` Execute செய்யும்."



```
             JavaScript Code
                     │
                     ▼
               Call Stack
                     │
     ┌───────────────┴──────────────┐
     │                              │
Sync Code                     Async Code
 Execute                           │
                                   ▼
                           Web APIs / Node APIs
                                    │
                           வேலை முடிந்ததும்
                                    │
                     ┌──────────────┴──────────────┐
                     ▼                             ▼
             Microtask Queue               Callback Queue
               (Promise)                  (setTimeout)
                     │                             │
                     └──────────────┬──────────────┘
                                    ▼
                               Event Loop
                                    │
                         Call Stack காலியா?
                                    │
                              ஆம் (Yes)
                                    │
              முதலில் Microtask → பிறகு Callback
```
