# Template literals

- Template literals are a modern JavaScript feature 
- (ES6) that make working with strings easier and more powerful.
- They use backticks instead of quotes: `before used "" now ``   `

#### 1. Basic Syntax
```
const name = "Saravanan";

console.log(`Hello ${name}`);

👉 Output:

Hello Saravanan

```
#### 2. String Interpolation ${} 
```
Instead of:

const msg = "Hello " + name + "!";

Use:

const msg = `Hello ${name}!`;

👉 Cleaner and more readable

```


#### 3. Multi-line Strings
```
const text = `
  This is line 1
  This is line 2
  This is line 3
`;

console.log(text);

👉 No need for \n
```
#### 4. Expressions inside ${}
```
const a = 5;
const b = 10;

console.log(`Sum is ${a + b}`);

👉 You can run JS expressions inside
```
#### 5. Function Calls
```
function greet(name) {
  return `Hi ${name}`;
}

console.log(`${greet("Saravanan")} 👋`);
```
#### 6. HTML Templates (Very Useful 🔥)
```
const name = "Saravanan";

const html = `
  <div>
    <h1>${name}</h1>
    <p>Welcome!</p>
  </div>
`;

document.body.innerHTML = html;
```
#### 7. Conditional Logic
```
const isLoggedIn = true;

const msg = `User is ${isLoggedIn ? "Online" : "Offline"}`;
8. Tagged Templates (Advanced)
function highlight(strings, value) {
  return `${strings[0]}**${value}**`;
}

console.log(highlight`Hello ${"Saravanan"}`);
```
