#  Data Types

#### 🔹 Primitive Types



```
    Primitive  →  single value



    let name = "Ram";        // String
    let age = 25;            // Number
    let isActive = true;     // Boolean
    let x = null;            // Null
    let y;                   // Undefined



```
#### 🔹 Reference Types



```    
    Reference → multiple values / memory reference



    let arr = [1, 2, 3];                       // Array
    let person = { name: "Ram", age: 25 };     // Object
```
