# this keyword

- this refers to the object that is currently executing the function.

 ```
    
    const person = {

        firstName: "Saravanan",
        lastName : "Durai",
        streetName : "2nd cross st, 4th ave west"
        location : "velachery"
        city     : "chennai"
        
        fullName : function () {
           return this.firstName + " " + this.lastName
        },

        fullAddress : function(){
            return this.streetName + " " + this.location + " " +this.city
        }

   };
   

   let candidateFullName = person.fullname();

 ```



### 🔹 call()

- call = run function now + set this
- Simple words Run now using this object”

```  
    const user = { name: "Saravanan" };

    function show() {
        console.log(this.name);
    }

    show.call(user);       👉   output : Saravanan


```


### 🔹 apply()

- apply = same as call, but arguments in array
- Simple words “Run now using this object (with array inputs)”

```

function show(age) {
  console.log(this.name, age);
}

const user = { name: "Saravanan" };
show.apply(user, [25]); // Saravanan 25


```


### 🔹 bind()

- bind = don’t run now, create new function
- 👉 Simple words: “Make a copy function with fixed this”


```
function show() {
  console.log(this.name);
}

const user = { name: "Saravanan" };

const fn = show.bind(user);

fn(); // Saravanan
```
