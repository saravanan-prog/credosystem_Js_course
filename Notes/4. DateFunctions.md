# Date functions?

- Date functions = tools to work with date & time

## 📦 Create a date

```
let now = new Date();

👉 This gives:
        current date
        current time
```

## Important Date Functions

#### 1. getFullYear() → year

```

let timeStamp   = new Date();
let currentYear = timeStamp.getFullYear();

console.log(currentYear);                // 👉 Output :  2026
     
```


#### 2. getMonth() → month
Basic Understand
```
0 -> Jan
1 -> Feb
.
.
.
11 -> Dec
```
Example
```

let timeStamp   = new Date();
let currentMonth = timeStamp.getMonth() + 1;

console.log(currentMonth);                // 👉 Output :  4

```




#### 3. getDate() → day (date)

Basic Understand
```
0 -> Sunday
1 -> Monday
.
.
.
6 -> Saturday
```


Example
```

let timeStamp   = new Date();
let currentDate = timeStamp.getDate();

console.log(currentDate);                // 👉 Output :  12
    
```

#### 4. getDay() → weekday

```

let timeStamp   = new Date();
let currentDay = timeStamp.getDay();

console.log(currentDay);                // 👉 Output :  Monday

👉 0 = Sunday, 1 = Monday ...
    
```

#### 5. getHours() → hour


```
let timeStamp   = new Date();
let hour = timeStamp.getHours();

console.log(hour);                // 👉 Output :  5
    
```

#### 6. getMinutes()

```
let timeStamp   = new Date();
let minutes = timeStamp.getMinutes()
```

#### 7. getSeconds()

```
let timeStamp   = new Date();
let second = timeStamp.getSeconds()
```


## ✏️ Set Date (change values)

#### 8. setFullYear()

```
let timeStamp   = new Date();
timeStamp.setFullYear(2030)

```

#### 9. setMonth()

```
let timeStamp   = new Date();
timeStamp.setMonth(0) // January

```
